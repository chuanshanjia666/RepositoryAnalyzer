\cabstract{
    随着开源软件的蓬勃发展，如何高效地评估代码质量、理解项目演进历史以及保障软件供应链安全成为重要挑战。本文设计并实现了一款综合性的软件仓库分析工具，旨在从 Git 提交历史、代码静态质量以及 GitHub 协作平台数据三个维度对软件项目进行全方位的画像。

    在 Git 分析方面，工具实现了交互式的提交历史可视化及多维度的贡献者统计；在代码分析方面，集成了复杂度计算、依赖树解析及安全漏洞扫描功能，能够自动发现潜在的代码缺陷与安全风险；在 GitHub 平台分析方面，针对 Issue、Pull Request 及 CI/CD 工作流（Actions）进行了深度挖掘，评估了项目的社区活跃度与流程安全性。实际测试表明，该工具能够生成直观的图表与详细的分析报告，为开发者和项目管理者提供了有价值的数据支持。
}
\ckeywords{代码分析；Git可视化；软件质量；GitHub Actions；漏洞扫描}

\etitle{Design and Implementation of Multi-dimensional Software Repository Analysis Tool}
\eabstract{
    With the booming development of open source software, efficiently evaluating code quality, understanding project evolution history, and ensuring software supply chain security have become important challenges. This thesis designs and implements a comprehensive software repository analysis tool aimed at profiling software projects from three dimensions: Git commit history, static code quality, and GitHub collaboration platform data.

    In terms of Git analysis, the tool implements interactive commit history visualization and multi-dimensional contributor statistics. For code analysis, it integrates complexity calculation, dependency tree parsing, and security vulnerability scanning to automatically discover potential code defects and security risks. Regarding GitHub platform analysis, it conducts deep mining on Issues, Pull Requests, and CI/CD workflows (Actions) to evaluate community activity and process security. Practical tests show that the tool can generate intuitive charts and detailed analysis reports, providing valuable data support for developers and project managers.
}
\ekeywords{Code Analysis; Git Visualization; Software Quality; GitHub Actions; Vulnerability Scanning}
