\section{代码复杂度分析}

代码复杂度是衡量软件可维护性的核心指标，本项目基于\texttt{radon}库，通过\texttt{AdvancedRadonAnalyzer}模块实现自动化复杂度计算与可视化分析。

\subsection{分析方法与实现}
模块遍历仓库中所有Python文件，基于抽象语法树（AST）计算以下核心指标：
\begin{itemize}
    \item \textbf{圈复杂度 (Cyclomatic Complexity, CC)}：统计代码线性独立路径数量衡量逻辑复杂性，通过\texttt{radon.complexity.cc\_visit}解析代码块，统计if/while/for等控制流结构
    \item \textbf{可维护性指数 (Maintainability Index, MI)}：利用\texttt{radon.metrics.mi\_visit}计算0-100分的综合评分，结合圈复杂度、代码行数、Halstead体积和注释比例
\end{itemize}

\subsection{核心实现代码}
\texttt{AdvancedRadonAnalyzer}类核心实现如下：

\begin{verbatim}
class AdvancedRadonAnalyzer:
    def __init__(self, repo_path, output_dir):
        self.repo_path = Path(repo_path)
        self.output_dir = Path(output_dir)

    def analyze_file(self, file_path):
        """分析单个文件复杂度"""
        with open(file_path, 'r', encoding='utf-8') as f:
            code = f.read()

        # 计算圈复杂度与可维护性指数
        cc_results = cc_visit(code)
        mi_result = mi_visit(code, True)

        return {
            'file': str(file_path),
            'cc_complexity': len(cc_results),
            'mi_score': mi_result,
            'loc': len(code.split('\n'))
        }

    def batch_analyze(self):
        """批量分析所有Python文件"""
        python_files = list(self.repo_path.rglob('*.py'))
        results = []

        for file_path in python_files:
            try:
                result = self.analyze_file(file_path)
                results.append(result)
            except Exception as e:
                print(f"分析文件 {file_path} 出错: {e}")

        return results
\end{verbatim}

\section{项目依赖与安全审计}

针对软件开发中的"供应链安全"问题，\texttt{dependency\_analyzer.py}模块基于\texttt{pipdeptree}和\texttt{safety}工具实现深度依赖分析。

\subsection{分析维度}
\begin{itemize}
    \item \textbf{依赖树解析}：调用\texttt{pipdeptree --json}命令解析环境依赖关系，构建完整依赖树，识别直接依赖及隐蔽的传递依赖
    \item \textbf{漏洞数据库比对}：集成\texttt{safety}工具，将依赖版本与CVE漏洞数据库比对，自动标记存在安全风险的包版本
\end{itemize}

\section{代码漏洞扫描 (SAST)}

为发现代码层面潜在安全隐患，项目集成\texttt{bandit}作为静态应用程序安全测试（SAST）工具。

\subsection{扫描机制}
\texttt{vulnerability\_scanner.py}模块封装\texttt{BanditManager}，不执行代码，仅将Python源码解析为AST，通过插件匹配已知漏洞模式：
\begin{itemize}
    \item 硬编码敏感信息（密码、API Key）
    \item 弱加密算法（MD5、SHA1）使用
    \item 危险函数调用（eval()、subprocess.Popen的Shell注入风险）
    \item 不安全网络绑定（如绑定到0.0.0.0）
\end{itemize}

\subsection{风险评估}
扫描结果分为High、Medium、Low三个风险等级，图\ref{fig:vulnerability_viz}直观展示各类风险分布，为安全修复优先级提供数据支撑。
