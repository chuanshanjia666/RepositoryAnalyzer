\section{基于GitGraph的Git提交历史可视化}

本分析工具内置\texttt{html\_generator.py}模块，用于生成Git提交历史可视化报告。该模块读取Git仓库提交日志（含哈希值、作者、日期、提交信息及父提交关系），并将结构化数据注入HTML模板，输出交互式可视化页面。

\subsection{核心实现}

\texttt{html\_generator.py}核心实现如下：

\begin{verbatim}
def generate_git_tree_html(commits, repo_url):
    """生成Git提交历史HTML可视化页面"""
    commits_data = []
    for commit in commits:
        commit_info = {
            'hash': commit['hash'],
            'hashFull': commit['hashFull'],
            'author': commit['author'],
            'date': commit['date'],
            'message': commit['message'],
            'parents': commit['parents']
        }
        commits_data.append(commit_info)

    # 渲染模板并保存文件
    html_content = render_template('git_tree_template.html',
                                 commits=commits_data,
                                 repo_url=repo_url)
    
    with open('git_tree.html', 'w', encoding='utf-8') as f:
        f.write(html_content)

    return 'git_tree.html'
\end{verbatim}

前端可视化采用\texttt{gitgraph.js}开源库，可直观展示Git分支结构、合并历史及提交节点。生成的\texttt{git\_tree.html}支持交互式浏览，用户可查看项目演进路线、分支合并情况及开发者提交记录。

结果如图\ref{fig:git_tree}所示，展示了COMTool项目Git提交历史。每个节点代表一次提交，节点连线表示父子关系，不同颜色区分分支/标签，鼠标悬停可查看提交详情。

\section{多维度Git仓库分析}

本节详细介绍\texttt{analyze.py}模块实现的多维度Git仓库分析功能，通过量化数据揭示项目开发节奏、团队结构及代码演进规律。

\subsection{实现技术与工具}

分析工具基于Python开发，核心依赖以下开源库：
\begin{itemize}
    \item \textbf{GitPython}：与本地Git仓库交互，遍历提交历史、提取提交哈希/作者/时间戳/文件变更统计等元数据
    \item \textbf{Matplotlib}：可视化引擎，配置中文字体（SimHei/Source Han Sans CN）确保中文标签正常显示
    \item \textbf{Pandas}：高效处理时间序列数据，支持数据聚合、重采样与统计分析
    \item \textbf{Collections (Counter)}：快速统计作者提交次数、关键词频率等数据
\end{itemize}

\subsection{核心分析函数实现}

\texttt{analyze.py}关键分析函数如下：

\begin{verbatim}
def analyze_authors(commits):
    """分析开发者贡献"""
    author_count = Counter()
    for commit in commits:
        author = commit.get('author', 'Unknown')
        author_count[author] += 1
    return author_count.most_common(10)

def analyze_monthly_activity(commits):
    """分析月度活跃度"""
    monthly_data = defaultdict(int)
    for commit in commits:
        date_str = commit.get('date', '')
        if date_str:
            month = date_str[:7]  # YYYY-MM
            monthly_data[month] += 1
    return dict(sorted(monthly_data.items()))

def analyze_keywords(commits):
    """分析提交信息关键词"""
    keywords = {
        'add': ['add', '新增', '增加', 'create', 'new'],
        'fix': ['fix', '修复', 'bug', '解决'],
        'update': ['update', '更新', 'upgrade', '优化'],
        'refactor': ['refactor', '重构', '优化', '改进'],
        'remove': ['remove', '删除', 'del', 'rm']
    }

    keyword_count = Counter()
    for commit in commits:
        message = commit.get('message', '').lower()
        for category, words in keywords.items():
            if any(word in message for word in words):
                keyword_count[category] += 1
    return dict(keyword_count)
\end{verbatim}

\subsection{分析维度详解}

\subsubsection{开发活跃度分析}

开发活跃度是衡量项目生命周期的核心指标，工具从宏观月度趋势和微观时段分布两个维度分析。

\textbf{月度活跃度趋势}：
提取提交日期并按月份统计提交量，可清晰反映项目起步期、爆发期及平稳维护期。

\textbf{实现机制}：
\begin{verbatim}
def plot_monthly_activity(monthly_data, output_path):

\textbf{全天时段提交分布}：
提取提交时间的小时属性，分析开发者工作习惯，反映主力团队工作时区及加班情况。

\textbf{实现机制}：
\begin{verbatim}
def analyze_hourly_distribution(commits):
    """分析全天时段提交分布"""
    hourly_count = Counter()
    for commit in commits:
        date_str = commit.get('date', '')
        if date_str and len(date_str) > 13:
            hour = int(date_str[11:13])
            hourly_count[hour] += 1
    
    # 补全0-23小时数据
    for hour in range(24):
        hourly_count[hour] = hourly_count.get(hour, 0)
    return dict(sorted(hourly_count.items()))

def plot_hourly_activity(hourly_data, output_path):

def plot_author_contributions(author_data, output_path):

\subsubsection{代码演进与质量分析}

代码量变化直观反映软件成长过程，工具从净行数演变和增删趋势两方面分析。

\textbf{代码行数 (LOC) 演变}：
累加每次提交的新增/删除行数，计算净行数累计曲线，陡峭上升对应新功能开发，平缓/下降对应重构或清理死代码。

\textbf{实现机制}：
\begin{verbatim}
def analyze_loc_growth(commits):
    """分析代码行数演变"""
    loc_data = []
    total_loc = 0
    for commit in commits:
        insertions = commit.get('stats', {}).get('insertions', 0)
        deletions = commit.get('stats', {}).get('deletions', 0)
        net_change = insertions - deletions
        total_loc += net_change

        loc_data.append({
            'date': commit.get('date', ''),
            'insertions': insertions,
            'deletions': deletions,
            'net_change': net_change,
            'total_loc': total_loc
        })
    return loc_data

def plot_loc_growth(loc_data, output_path):
    """绘制代码行数演变图"""
    plt.figure(figsize=(12, 6))
    dates = [item['date'] for item in loc_data]
    total_loc = [item['total_loc'] for item in loc_data]

    plt.plot(dates, total_loc, linewidth=2, color='green')
    plt.title('代码库净行数演变趋势', fontsize=16, fontweight='bold')
    plt.xlabel('时间', fontsize=12)
    plt.ylabel('累计代码行数', fontsize=12)
    plt.xticks(rotation=45)
    plt.grid(True, alpha=0.3)
    plt.tight_layout()

    plt.savefig(output_path, dpi=300, bbox_inches='tight')
    plt.close()
\end{verbatim}

\subsubsection{提交行为语义分析}

对Commit Message进行文本挖掘，理解开发者核心工作内容。

\textbf{关键词分布分析}：
针对中文开发场景定义关键词映射，通过模式匹配生成分布饼图，直观判断项目阶段（新增占比高=迭代期，修复占比高=维护期）。

\textbf{实现机制}：
\begin{verbatim}
def plot_keywords_distribution(keyword_data, output_path):
    """绘制关键词分布饼图"""
    plt.figure(figsize=(8, 8))
    labels = list(keyword_data.keys())
    sizes = list(keyword_data.values())

    # 中文标签映射
    label_map = {
        'add': '新增/Add',
        'fix': '修复/Fix',
        'update': '更新/Update',
        'refactor': '重构/Refactor',
        'remove': '删除/Remove'
    }
    display_labels = [label_map.get(label, label) for label in labels]

    colors = ['#ff9999', '#66b3ff', '#99ff99', '#ffcc99', '#ff99cc']
    plt.pie(sizes, labels=display_labels, autopct='%1.1f%%', 
            startangle=90, colors=colors)
    plt.title('提交信息高频关键词分布', fontsize=16, fontweight='bold')
    plt.axis('equal')

    plt.savefig(output_path, dpi=300, bbox_inches='tight')
    plt.close()
\end{verbatim}

\textbf{修改热点分析}：
统计提交涉及的文件路径，识别修改频率最高的目录/模块，这些热点区域是业务核心且易出Bug，需重点关注。

\textbf{实现机制}：
\begin{verbatim}
def analyze_file_hotspots(commits):
    """分析文件修改热点"""
    file_count = Counter()
    for commit in commits:
        modified_files = commit.get('files', [])
        for file_path in modified_files:
            dir_path = os.path.dirname(file_path)
            if dir_path:
                file_count[dir_path] += 1
    return file_count.most_common(10)

def plot_file_hotspots(hotspot_data, output_path):
    """绘制修改热点分析图"""
    plt.figure(figsize=(10, 6))
    directories = [item[0] for item in hotspot_data]
    counts = [item[1] for item in hotspot_data]

    bars = plt.barh(directories, counts, color='lightblue', edgecolor='navy')
    plt.title('最常被修改的代码目录 (热点分析)', fontsize=16, fontweight='bold')
    plt.xlabel('修改次数', fontsize=12)
    plt.ylabel('目录路径', fontsize=12)

    # 添加数值标签
    for bar, count in zip(bars, counts):
        plt.text(bar.get_width() + max(counts)*0.01,
