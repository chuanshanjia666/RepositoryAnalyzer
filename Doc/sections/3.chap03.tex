\section{代码复杂度分析}

代码复杂度是衡量软件可维护性的核心指标，本项目基于\texttt{radon}库，通过\texttt{AdvancedRadonAnalyzer}模块实现自动化复杂度计算与可视化分析。

\subsection{分析方法与实现}
模块遍历仓库中所有Python文件，基于抽象语法树（AST）计算以下核心指标：
\begin{itemize}
    \item \textbf{圈复杂度 (Cyclomatic Complexity, CC)}：统计代码线性独立路径数量衡量逻辑复杂性，通过\texttt{radon.complexity.cc\_visit}解析代码块，统计if/while/for等控制流结构
    \item \textbf{可维护性指数 (Maintainability Index, MI)}：利用\texttt{radon.metrics.mi\_visit}计算0-100分综合评分，结合圈复杂度、代码行数、Halstead体积和注释比例
\end{itemize}

\section{项目依赖与安全审计}

针对软件开发中的"供应链安全"问题，\texttt{DependencyAnalyzer}模块基于\texttt{pipdeptree}和\texttt{safety}工具实现深度依赖分析。

\subsection{分析维度}
\begin{itemize}
    \item \textbf{依赖树解析}：调用\texttt{pipdeptree --json}命令解析环境依赖关系，构建完整依赖树，识别直接依赖及隐蔽的传递依赖
    \item \textbf{漏洞数据库比对}：集成\texttt{safety}工具，将依赖版本与CVE漏洞数据库比对，自动标记存在安全风险的包版本
\end{itemize}

\subsection{核心实现}
\texttt{DependencyAnalyzer}关键实现如下：

\begin{verbatim}
class DependencyAnalyzer:
    def analyze_python_deps(self):
        """分析Python依赖"""
        # 获取依赖树
        result = subprocess.run(
            ['pipdeptree', '--json'],
            capture_output=True, text=True
        )

        if result.returncode == 0:
            deps = json.loads(result.stdout)
            return self._process_dependencies(deps)
        else:
            raise RuntimeError("依赖分析失败")

    def _check_vulnerabilities(self, deps):
        """检查依赖漏洞"""
        result = subprocess.run(
            ['safety', 'check', '--json'],
            capture_output=True, text=True
        )

        vulnerabilities = []
        if result.returncode != 0:
            try:
                vulnerabilities = json.loads(result.stdout)
            except:
                pass

        return vulnerabilities
\end{verbatim}

\section{代码漏洞扫描 (SAST)}

为发现代码层面潜在安全隐患，项目集成\texttt{bandit}作为静态应用程序安全测试（SAST）工具。

\subsection{扫描机制}
\texttt{AdvancedVulnerabilityScanner}模块封装\texttt{BanditManager}，不执行代码，仅将Python源码解析为AST，通过插件匹配已知漏洞模式：
\begin{itemize}
    \item 硬编码敏感信息（密码、API Key）
    \item 弱加密算法（MD5、SHA1）使用
    \item 危险函数调用（eval()、subprocess.Popen的Shell注入风险）
    \item 不安全网络绑定（如绑定到0.0.0.0）
\end{itemize}

\subsection{实现机制}
漏洞扫描核心实现如下：

\begin{verbatim}
class AdvancedVulnerabilityScanner:
    def __init__(self, repo_path, output_dir):
        self.repo_path = Path(repo_path)
        self.output_dir = Path(output_dir)

    def advanced_bandit_scan(self):
        """执行Bandit漏洞扫描"""
        # 配置扫描参数
        cmd = [
            'bandit', '-r', str(self.repo_path),
            '-f', 'json', '-o', str(self.output_dir / 'bandit_report.json')
        ]

        result = subprocess.run(cmd, capture_output=True, text=True)

        # 解析结果（返回1表示发现问题）
        if result.returncode in [0, 1]:
            return self._parse_bandit_results()
        else:
            raise RuntimeError(f"Bandit扫描失败: {result.stderr}")

    def _parse_bandit_results(self):
        """解析扫描结果"""
        report_file = self.output_dir / 'bandit_report.json'
        if report_file.exists():
            with open(report_file, 'r') as f:
                data = json.load(f)

            # 按严重程度统计
            severity_count = {'high': 0, 'medium': 0, 'low': 0}
            for issue in data.get('results', []):
                severity = issue.get('issue_severity', 'low')
                if severity in severity_count:
                    severity_count[severity] += 1

            return {
                'total_issues': len(data.get('results', [])),
                'severity_count': severity_count,
                'results': data.get('results', [])
            }

        return {'total_issues': 0, 'severity_count': {'high': 0, 'medium': 0, 'low': 0}, 'results': []}
\end{verbatim}

\section{GitHub 生态分析}

\subsection{安全 Issues 分析}
通过\texttt{GitHubIssueAnalyzer}模块分析Neutree/COMTool仓库近180天issues数据，模块基于PyGithub库实现，核心功能如下：

\begin{verbatim}
class GitHubIssueAnalyzer:
    def __init__(self, repo_owner, repo_name, output_dir, token=None):
        self.repo_owner = repo_owner
        self.repo_name = repo_name
        self.output_dir = Path(output_dir)
        self.github = Github(token) if token else Github()
        self.repo = self.github.get_repo(f"{repo_owner}/{repo_name}")

    def get_issues(self, days_back=180):
        """获取指定时间范围的issues"""
        since = datetime.now() - timedelta(days=days_back)
        issues = []

        for issue in self.repo.get_issues(state='all', since=since):
            issues.append({
                'number': issue.number,
                'title': issue.title,
                'body': issue.body or "",
                'state': issue.state,
                'created_at': issue.created_at,
                'labels': [label.name for label in issue.labels]
            })

        return issues

    def analyze_security_issues(self, issues):
        """分析安全相关issues"""
        security_keywords = [
            'vulnerability', 'security', 'cve', 'exploit', 'injection',
            'xss', 'rce', 'overflow', 'bypass', '权限', '漏洞', '安全'
        ]

        security_issues = []
        for issue in issues:
            text = f"{issue['title']} {issue['body']}".lower()
            if any(keyword.lower() in text for keyword in security_keywords):
                security_issues.append(issue)

        return {
            'security_issues': security_issues,
            'severity_count': self._classify_severity(security_issues)
        }
\end{verbatim}

\subsection{PR 分析}
通过\texttt{analyze\_pr\_repository}函数分析项目PR数据，实现PR协作效率全面评估：

\begin{verbatim}
def analyze_pr_repository(repo_full_name, days_threshold=7, github_token=None):
    """分析GitHub PR数据"""
    g = Github(github_token) if github_token else Github()
    repo = g.get_repo(repo_full_name)

    pr_data = []
    for pr in repo.get_pulls(state='all'):
        pr_info = {
            'number': pr.number,
            'title': pr.title,
            'state': pr.state,
            'created_at': pr.created_at,
            'merged_at': pr.merged_at,
            'closed_at': pr.closed_at,
            'review_comments': pr.review_comments,
            'comments': pr.comments,
            'additions': pr.additions,
            'deletions': pr.deletions
        }
        pr_data.append(pr_info)

    # 计算核心指标
    total_pr = len(pr_data)
    merged_pr = len([pr for pr in pr_data if pr['state'] == 'merged'])
    closed_pr = len([pr for pr in pr_data if pr['state'] == 'closed' and not pr['merged_at']])

    # 识别僵尸PR
    zombie_prs = []
    for pr in pr_data:
        if pr['state'] == 'open':
            days_open = (datetime.now() - pr['created_at'].replace(tzinfo=None)).days
            if days_open > days_threshold:
                zombie_prs.append(pr)

    return {
        'total_pr': total_pr,
        'merged_pr': merged_pr,
        'closed_pr': closed_pr,
        'merge_rate': (merged_pr / total_pr) * 100 if total_pr > 0 else 0,
        'zombie_pr_count': len(zombie_prs),
        'zombie_pr_rate': (len(zombie_prs) / total_pr) * 100 if total_pr > 0 else 0
    }
\end{verbatim}

分析覆盖23个PR，核心指标如下：
\begin{itemize}
    \item 总PR数量：23个
    \item 合并率：69.57\%
    \item 拒绝率：21.74\%
    \item 僵尸PR率：8.7\%
    \item 平均审查时间：7.86小时
    \item 平均评论数：1.65条
\end{itemize}

指标表明项目开发流程健康，PR合并率高、审查效率良好，僵尸PR率控制在较低水平。

\subsection{GitHub Actions 工作流分析}
通过\texttt{GitHubActionsAnalyzer}模块分析项目CI/CD流程，实现工作流安全性与效率全面评估：

\begin{verbatim}
class GitHubActionsAnalyzer:
    def __init__(self, repo_owner, repo_name, output_dir, token=None):
        self.repo_owner = repo_owner
        self.repo_name = repo_name
        self.output_dir = Path(output_dir)
        self.github = Github(token) if token else Github()
        self.repo = self.github.get_repo(f"{repo_owner}/{repo_name}")

    def get_workflows(self):
        """获取所有Actions工作流"""
        workflows = []
        try:
            for workflow in self.repo.get_workflows():
                workflows.append({
                    'id': workflow.id,
                    'name': workflow.name,
                    'path': workflow.path,
                    'state': workflow.state
                })
        except Exception as e:
            print(f"获取工作流失败: {e}")

        return workflows

    def analyze_workflow_security(self, workflows):
        """分析工作流安全性"""
        security_issues = []

        for workflow in workflows:
            try:
                file_content = self.repo.get_contents(workflow['path'])
                content = file_content.decoded_content.decode('utf-8')

                # 检测安全风险模式
                risks = self._check_security_patterns(content)
                if risks:
                    security_issues.append({
                        'workflow': workflow['name'],
                        'risks': risks
                    })

            except Exception as e:
                print(f"分析工作流 {workflow['name']} 失败: {e}")

        return security_issues

    def _check_security_patterns(self, content):
        """检查工作流安全风险模式"""
        risks = []
        dangerous_patterns = [
            r'curl.*\|\s*bash',  # curl | bash 风险
            r'wget.*\|\s*bash',  # wget | bash 风险
            r'uses:\s*actions/.*@v\d',  # 使用版本标签而非commit hash
        ]

        for pattern in dangerous_patterns:
            if re.search(pattern, content, re.IGNORECASE):
                risks.append(f"检测到危险模式: {pattern}")

        return risks
\end{verbatim}

    \item 安全问题数量：0个
\end{itemize}

项目CI/CD安全性表现良好，\textbf{未发现Actions工作流安全问题}，自动化流程配置安全可靠。
